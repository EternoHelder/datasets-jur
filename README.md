# datasets-jur

Repositório independente de datasets jurídicos.

## Sobre

Este repositório contém datasets de dados jurídicos para análise e pesquisa. Ele é completamente independente e separado do projeto **ecoiuris**.

## Estrutura

```
datasets-jur/
├── dados/          # Datasets brutos e processados
├── scripts/        # Scripts de processamento e limpeza de dados
└── docs/           # Documentação dos datasets
```

## Utilização

Os datasets disponíveis neste repositório podem ser utilizados para:

- Análise de dados jurídicos
- Pesquisa acadêmica
- Desenvolvimento de soluções legais
